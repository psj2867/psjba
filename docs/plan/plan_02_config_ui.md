## 3. 설정 파일 (config.ini)

INI 파일 하나로 모든 설정 관리.

**[llm] — LLM 관련 (필수: api_key, model)**
- api_key: LLM API 키 (UI에서 입력, config.ini에는 암호화된 값으로 저장)
- model: 사용할 모델명 (기본값 `qwen/qwen3.6-27b`)
- url: LLM API 엔드포인트 URL (기본값 https://openrouter.ai/api/v1)
- max_tokens: 최대 토큰 수 (기본값 4096)
- temperature: 생성 온도 (기본값 0.0)
- timeout: API 타임아웃 (초, 기본값 60)

**[cdp] — CDP 관련**
- host: CDP 호스트 (기본값 127.0.0.1)
- port: CDP 포트 (기본값 9222)
- connection_timeout: CDP 연결 타임아웃 (기본값 1.0초, 필요시 ini에서 조정)

**[chrome] — Chrome 관련**
- path: Chrome 실행 파일 전체 경로
- user_data_dir: 사용자 프로필 디렉토리 (선택, 미지정 시 임시 프로필)
- headless: 헤드리스 모드 여부 (기본값 false)

**[sqlite] — SQLite 관련**
- path: DB 파일 경로 (기본값 ./browser_agent.data)

**[agent] — Agent 관련**
- sliding_window_size: 슬라이딩 윈도우 크기 (기본값 30)
- cron_timeout: 각 크론 작업별 최대 실행 시간 (기본값 300, 단위: 초)
- max_tool_calls: 프롬프트 당 최대 tool call 횟수 (기본값 30, 무한루프 방지)

**[workspace] — Workspace 관련**
- workspace_dir: 프로그램이 읽고 쓸 수 있는 작업 폴더 (기본값 ./psjba_temp)

**[ui] — UI 관련**
- font_size
- max_chat_lines: 대화 로그 최대 줄 수
- language: ko / en (기본값 ko, 에러 메시지 및 UI 표시 언어)

**[logging] — 로깅 관련**
- level: 로그 레벨 (disabled / DEBUG / INFO / WARNING / ERROR / CRITICAL, **기본값 disabled = 파일 로깅 비활성화**, 콘솔 출력만 유지)
- path: 로그 파일 경로 (기본값 ./psjba.log, level이 disabled면 무시됨)

### API Key 암호화 (api_key)

**목적:** config.ini에는 `api_key = <암호문>` 형태로 저장, 평문은 UI 메모리에서만 유지.

**동작 방식:**
- UI 설정 탭에서 사용자가 입력하는 필드명: `api_key`
- 저장 시 암호화 → config.ini에 `api_key = <암호문>` 기록
- 불러올 때 복호화 → 메모리에 평문 `api_key` 유지

**암호화 방식:**
- 라이브러리: `cryptography.fernet` (pip install cryptography)
- 암호화 키: **머신 고유 MAC 주소 기반 파생 키** (하드코딩 없음)
  ```python
  import hashlib, base64, uuid
  from cryptography.fernet import Fernet

  machine_id = uuid.getnode()  # MAC 주소 (48bit)
  salt = b"psjba_2024"
  key = hashlib.pbkdf2_hmac("sha256", str(machine_id).encode(), salt, 100000)
  fernet_key = base64.urlsafe_b64encode(key[:32])
  cipher = Fernet(fernet_key)
  ```
- config.ini에는 `api_key = gAAAAAB...` 형태로 저장
- 메모리에서만 평문 api_key 유지, 디스크에는 절대 평문 저장 안 함

**주의사항:**
- MAC 주소 변경 (Wi-Fi/Wired 카드 교체 등) 시 기존 api_key(암호문) 복호화 불가
  → 이 경우 앱에서 "암호화 키가 변경되어 복호화할 수 없습니다. API 키를 다시 입력해주세요." 안내
  → 사용자가 새 API 키를 입력하면 새 MAC 주소로 다시 암호화하여 저장

## 4. SQLite 스키마

총 4개 테이블로 구성되며, 시작 시 스키마 버전을 비교하여 관리한다.

### psjba_meta — 메타 정보
키-값 저장소. 프로그램 자체의 메타 정보를 보관한다.
- schema_version: 현재 "1" (시작 시 비교, 불일치 시 오류)
- app_version: "0.1.0"
- last_run_at: 마지막 실행 시간
- current_session_id: 현재 활성 대화 세션 ID (UUID)

### psjba_session — 대화 세션
대화 단위를 그룹핑하는 세션 테이블.
- id: UUID
- title: 세션 제목 (**생성 시 "새 대화"로 저장**, 첫 번째 user 메시지 전송 후 앞 50자로 자동 갱신)
- type: chat / cron (기본값 chat, 크론 작업 실행 세션 구분)
- cron_job_id: psjba_cron_job 참조 (UUID, nullable, FK, cron 타입 세션만 값 있음)
- created_at, updated_at
- status: active / archived / deleted

### psjba_message — 개별 메시지
LLM 왕복 단위. user, assistant, tool, system 롤을 모두 저장.
tool role 메시지의 content에는 도구 실행 결과와 함께 duration_ms, status가 JSON에 포함된다.
- id: UUID
- session_id: psjba_session 참조
- role: user / assistant / tool / system
- content: 메시지 본문 (JSON 형식, tool_calls 포함 가능. tool role의 경우 `{"result": "...", "duration_ms": 1200, "status": "success"}` 형태)
- token_usage: 토큰 사용량 (JSON)
- model: 사용된 모델명
- created_at

### psjba_cron_job — 크론 작업
예약된 작업 정보.
- id: UUID
- name: 작업 이름
- schedule: 크론 표현식 (문자열, 5필드 표준)
- prompt: 실행할 프롬프트
- status: enable / disable / deleted (기본값 enable, 삭제는 실제 row 삭제 대신 status='deleted')
- last_run_at: 마지막 실행 시간
- next_run_at: 다음 실행 시간
- created_at, updated_at

### 버전 관리
시작 시 psjba_meta에서 schema_version 값을 읽어 현재 코드의 SCHEMA_VERSION과 비교한다. DB가 없으면 새로 생성하고 버전을 기록한다. 값이 다르면 "Schema version mismatch" 오류를 출력하고 프로그램을 종료한다.

## 5. UI 구조 (PySide6)

### 메인 윈도우 — 최대한 심플

```
┌──────────────────────────────────────────────────────────┐
│ ⚙️                                   🔗 Chrome 연결하기 │
│ ┌──────────────────────────────────────────────────────┐ │
│ │  ┌─ 세션 로그 영역 (QScrollArea) ─────────────────┐ │ │
│ │  │                                                 │ │ │
│ │  │              👤 사용자 메시지 1                 │ │ │
│ │  │                                                 │ │ │
│ │  │  🤖 ┌──────────────────────────────────────┐   │ │ │
│ │  │     │ ▶ 툴 콜 1 (클릭 시 펼쳐짐)           │   │ │ │
│ │  │     │ ▶ 툴 콜 2 (클릭 시 펼쳐짐)           │   │ │ │
│ │  │     ├──────────────────────────────────────┤   │ │ │
│ │  │     │ AI 최종 답변 (항상 펼쳐짐)           │   │ │ │
│ │  │     └──────────────────────────────────────┘   │ │ │
│ │  │                                                 │ │ │
│ │  │              👤 사용자 메시지 2                 │ │ │
│ │  │                                                 │ │ │
│ │  │  🤖 ┌──────────────────────────────────────┐   │ │ │
│ │  │     │ ▶ 툴 콜 1 (클릭 시 펼쳐짐)           │   │ │ │
│ │  │     ├──────────────────────────────────────┤   │ │ │
│ │  │     │ AI 최종 답변 (항상 펼쳐짐)           │   │ │ │
│ │  │     └──────────────────────────────────────┘   │ │ │
│ │  └─────────────────────────────────────────────────┘ │ │
│ │                                                     │ │
│ │ ┌──────────────────────────────────────────────────┐ │ │
│ │ │ [프롬프트 입력창]              [🔄][전송]      │ │ │
│ │ └──────────────────────────────────────────────────┘ │ │
│ └──────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

- **좌측 상단 (⚙️)**: 톱니바퀴 설정 버튼 — 클릭 시 설정 창(별도 QDialog) 열림
- **우측 상단 (🔗 Chrome 상태 버튼)**: 크롬 연결 상태 표시 + 토글 버튼
- **세션 로그 영역**: 메인 윈도우 상단, 스크롤 가능한 QScrollArea. **현재 대화 세션(chat)만 표시** (크론 세션은 설정 창 → 로그 탭에서 조회)

#### 세션 로그 표시 규칙

| 항목 | 표시 방식 |
|------|----------|
| **사용자 메시지** | 우측 정렬. 요청 텍스트 + 👤 아이콘 (또는 SVG 사람 아이콘) |
| **AI 응답 블록** | 좌측 정렬. 🤖 아이콘 (또는 SVG 로봇 아이콘) + 응답 내용 |
| **툴 콜 (Tool Call)** | AI 응답 블록 내에서 **접힌 상태(collapsible)**로 표시. ▶ 아이콘 + 툴명. 사용자 클릭 시 펼쳐져서 입출력 세부 내용 표시 |
| **최종 답변** | AI 응답 블록 내에서 **항상 펼쳐진 상태**로 표시. 툴 콜들과 구분선으로 분리. **가장 마지막 텍스트 응답**이 최종 답변 (tool_calls가 없는 assistant 메시지 또는 tool_calls 이후의 마지막 텍스트 메시지) |
| **구조** | `AI 블록 = (툴 콜들 → 접힘) + (최종 답변 → 펼침)` |

- **툴 콜 접힘 기본값**: 모든 툴 콜은 기본적으로 접힌 상태. 사용자가 ▶ 클릭 시 해당 툴 콜의 상세(입력 파라미터, 실행 결과 등)가 펼쳐짐
- **툴 콜 표시 내용 (펼쳤을 때)**: `tool_name(input_params) → result` 형태
- **구분선**: 툴 콜 영역과 최종 답변 사이에 얇은 구분선

#### 크롬 상태 버튼 상세

| 상태 | 표시 텍스트 | 테두리 | 배경색 | 텍스트색 | 버튼 클릭 동작 |
|------|-----------|--------|--------|---------|-------------|
| Chrome 연결하기 | `🔗 Chrome 연결하기` | 있음 (1px solid) | 어두운 회색 | 흰색 | 클릭 시 연결 시도 |
| Chrome 연결 중... | `🔗 Chrome 연결 중...` | 1px solid (점선) | 회색 배경 | 흰색 | (자동 전환) |
| Chrome 연결됨 | `🔗 Chrome 연결됨` | 있음 (1px solid) | 초록 계열 | 흰색 | 클릭 시 연결 해제 |

**버튼 클릭 로직 (안 됨 → 됨):**
```
1. 1초 타임아웃으로 CDP 연결 시도 (기존 Chrome에 붙어보기)
2. 실패하면 → config.ini의 Chrome 경로(path)로 Chrome 실행
3. 실행 완료 후 CDP 연결
4. 연결 성공 → "연결 됨"
5. 모두 실패 → "연결 안 됨" 유지
```

**프로그램 시작 시 동작:**
- 최초 실행 시 5초 타임아웃으로 CDP 연결 테스트
- 연결 성공 → "Chrome 연결됨" 상태로 시작
- 연결 실패 → "Chrome 연결하기" 상태로 시작
- (시작 시에는 Chrome 자동 실행 안 함, 사용자가 버튼 클릭할 때 실행)
- 연결 중 상태는 **점선 테두리 + 회색 배경**으로 진행 중임을 표시
- 연결 됨/안 됨은 **실선 테두리 + 상태색**으로 구분
- 각 상태별 색상으로 직관적 구분

**상태 천이:**
```
                    ┌─ (기존 Chrome 있음, 1초 연결 성공)
                    │
안 됨 ──(클릭)──→ 연결 중... ──── (1초 타임아웃) ──→ Chrome 실행 ──→ 연결 됨
                    │               (기존 Chrome 없음)
                 (실패)
                    ↓
                 안 됨  ←──(연결 해제)──
```

**프로그램 시작 시:** 5초 타임아웃 CDP 테스트 → 성공 시 "연결 됨", 실패 시 "연결 안 됨" (자동 실행 없음)

### 설정 창 (⚙️ 클릭 시 열리는 QDialog)

```
┌──────────────────────────────────────────────────┐
│  설정 창                                    - □ x │
├──────────────────────────────────────────────────┤
│  [ 설정 ]  [ CRON ]  [ 로그 ]   (상단 탭)        │
│                                                  │
│  ┌──────────────────────────────────────────────┐│
│  │                                              ││

└──────────────────────────────────────────────────┘
```

#### 탭 순서: 설정 → CRON → 로그

| 탭 | 설명 |
|----|------|
| **설정** | INI 설정 값 편집 (섹션별 그룹박스, 편집 가능, 우측 하단 저장 버튼) |
| **CRON** | 크론 작업 목록 (각 행: 설명/주기/상태 토글/로그 버튼). 주기 클릭 시 편집. 로그 버튼 → 해당 크론의 실행 세션 목록 → 세션 클릭 시 상세 로그. 3단계 드릴다운 구조 |
| **로그** | 모든 세션(대화+크론) 목록 — 2단계 드릴다운: Level 1 세션 목록(타입/시간/세션ID/처음요청프롬프트) → Level 2 세션 상세 로그 |

│  └─────────────────────────────────────────────────────┘  │
│                                            [💾 저장]       │
└──────────────────────────────────────────────────────────┘
```

#### 위젯 매핑 규칙

| INI 값 타입 | UI 위젯 |
|-----------|--------|
| 문자열 (str) | QLineEdit |
| 정수 (int) | QSpinBox (또는 QLineEdit + validator) |
| 실수 (float) | QDoubleSpinBox (또는 QLineEdit + validator) |
| 불리언 (bool, true/false) | QCheckBox |
| 선택 값 (예: language → ko/en) | QComboBox |

#### 키 설명 툴팁 (?)

각 키 이름(label) 옆에 `?` 아이콘을 배치하고, 마우스 호버 시 해당 키의 설명을 툴팁으로 표시한다.

- **툴팁 내용**: `plan_02_config_ui.md` Section 3에 정의된 각 키의 설명문 (예: "LLM API 제공자 (기본값 openrouter, openai 호환 API만 지원)")
- **구현 방식**: QLabel(QPixmap) + setToolTip() 또는 QLabel("?") + setToolTip()
- `?` 아이콘 스타일: 작은 회색 원 안에 흰색 `?` 텍스트 (12×12px), 클릭 불가, hover 시 hand cursor

#### Placeholder 규칙

- 기본값이 있는 필드 → **placeholder에 기본값 표시** (빈 입력 시 기본값 사용)
- **api_key**: placeholder는 `"API 키를 입력하세요"` 안내 텍스트. **실제 값이 입력되어 있으면** `••••••` (masked text)로 표시. 빈 값일 때만 placeholder 노출 (QLineEdit.setPlaceholderText())
- 빈 값이 허용되는 필드 (user_data_dir 등) → placeholder 없음

#### 저장 버튼

- 위치: **설정 탭 우측 하단, 스크롤 영역 밖** (QDialog 하단에 floating) — CRON/로그 탭의 추가 버튼과 **위치 분리** (추가 버튼은 탭 헤더 우측)
- 크기: 작은 아이콘 버튼 또는 텍스트 버튼 `💾 저장`
- **색상**: 파란색 계열 (`background-color: #1976D2; color: white;`) — CRON 추가 버튼(녹색)과 시각적 차별화
- 스크롤과 무관하게 항상 같은 위치에 고정
- 저장 시 동작:
  1. 각 섹션별 필드 값 읽기
  2. api_key 필드 → `cryptography.fernet` + MAC 주소 키로 암호화 → `api_key`로 저장 (INI 키명도 `api_key`)
  3. 나머지 값은 해당 INI 키에 그대로 저장
  4. config.ini 파일에 즉시 쓰기 (configparser)
  5. config.py의 인메모리 설정 캐시 갱신
  6. 저장 완료 토스트 메시지 (또는 상태 표시)
  7. **설정 탭 하단 저장 버튼 위에 작은 정보 텍스트**: "API 키는 MAC 주소 기반으로 암호화되어 저장됩니다"

#### 필수값 검증
- `api_key`가 비어있으면 → 저장 버튼 클릭 시 "API 키를 입력해주세요." 경고, 저장 중단
- `model`이 비어있으면 → "모델명을 입력해주세요." 경고, 저장 중단
- 나머지 필드는 빈 값 허용 (기본값 사용 또는 옵션 항목)

### CRON 탭 상세 — 3단계 드릴다운 구조

CRON 탭은 **3단계 드릴다운(drill-down)** 으로 동작하며, 각 단계는 같은 화면 영역 내에서 전환된다.

```
┌──────────────────────────────────────────────────────────┐
│  [ 설정 ]  [ CRON ▼ ]  [ 로그 ]          [➕ 추가]       │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  ┌─ CRON 콘텐츠 영역 (QStackedWidget으로 3개 뷰 전환) ──┐│
│  │                                                      ││
│  │  ● Level 1: 크론 작업 목록                          ││
│  │  ● Level 2: 특정 크론의 실행 세션 목록              ││
│  │  ● Level 3: 특정 세션의 상세 로그                   ││
│  │                                                      ││
│  └──────────────────────────────────────────────────────┘│
│                                                          │
└──────────────────────────────────────────────────────────┘
```

- **`➕ 추가` 버튼**: **탭 헤더 우측 끝** (설정/CRON/로그 탭과 같은 줄, 우측 정렬). 새 크론 작업 등록 다이얼로그 열림. **Level 1에서만 표시**, Level 2/3에서는 숨김 (현재 뷰에 집중)
- **색상**: 녹색 계열 (`background-color: #388E3C; color: white;`) — 설정 탭 저장 버튼(파랑)과 시각적 차별화
- **`✏️ 수정` / `🗑️ 삭제` / `▶ 실행`**: 각 크론 행의 우측에 액션 버튼으로 배치 (또는 행 우클릭 컨텍스트 메뉴)

##### 주기 편집 UI (드롭다운 클릭 시)

주기 버튼(`[매시간 00분 ▼]`)을 클릭하면 **QDialog** 또는 **인라인 편집 위젯**이 열린다.

```
┌── 주기 편집 ───────────────────────┐
│  작업: 매시간 날씨 체크            │
│                                    │
│  단위: [시간 ▼]  간격: [1]        │
│  (분/시간/일/주/월/직접입력)       │
│                                    │
│  ── 단위 선택 시 동적 필드 ──────  │
│  기준 분: [00]                    │
│  (시간 단위일 때만 표시)           │
│                                    │
│  ┌──────────────────────────────┐  │
│  │ 미리보기: 0 * * * *          │  │
│  │ (매시간 00분)                │  │
│  └──────────────────────────────┘  │
│                                    │
│          [취소]     [💾 저장]      │
└────────────────────────────────────┘
```

- **단위 선택기** (`QComboBox`): `분`, `시간`, `일`, `주`, `월`, `직접입력`
- **간격** (`QSpinBox`): 단위별 기본값과 범위로 동적 조정
- **단위별 동적 필드** (단위 선택 시 해당 필드만 표시):

| 단위 | 간격 기본값 | 범위 | 표시 필드 | cron 예시 | 설명 |
|------|------------|------|----------|-----------|------|
| **분** | 5 | 1~59 | (없음) | `*/5 * * * *` | 매 5분 |
| **시간** | 1 | 1~24 | 기준 분 (0~59) | `30 */2 * * *` | 매 2시간 30분 |
| **일** | 1 | 1~31 | 시간 (0~23), 분 (0~59) | `0 10 */3 * *` | 매 3일 10:00 |
| **주** | 1 | 1~4 | 요일 체크박스, 시간, 분 | `0 10 * * 1,3,5` | 매주 월/수/금 10:00 |
| **월** | 1 | 1~12 | 날짜 (1~31), 시간, 분 | `0 10 1 * *` | 매월 1일 10:00 |
| **직접입력** | — | — | cron 표현식 입력 필드 | 사용자 입력 | 자유 형식 |

- **기준 분** (시간 단위): QSpinBox (0~59), 기본값 00
- **시간/분** (일/주/월 단위): QSpinBox (시: 0~23, 분: 0~59)
- **요일 체크박스** (주 단위): [월] [화] [수] [목] [금] [토] [일] — 다중 선택
- **날짜** (월 단위): QSpinBox (1~31)
- **미리보기**: cron 표현식 + 사람이 읽기 쉬운 설명을 실시간 업데이트
- **저장 시**: DB `schedule` 업데이트 + 스케줄러 `next_run_at` 재계산

##### 카드 액션 버튼 (옵션)

각 카드 우측 상단에 `⋮` (메뉴) 버튼을 배치하거나, 카드 내 추가 버튼 영역 활용:

| 버튼 | 동작 |
|------|------|
| `▶ 실행` | 해당 크론을 **지금 즉시 수동 실행**. 새 세션 생성 + LangGraph 실행 |
| `✏️ 수정` | 작업 이름/프롬프트 편집 다이얼로그 열림 |
| `🗑️ 삭제` | 확인 다이얼로그 → "관련 세션 N개가 archived 처리됩니다" → 삭제 |

##### 헤더 영역

| 요소 | 설명 |
|------|------|
| `◀ 크론 목록으로` | 좌측 상단 뒤로가기 버튼. 클릭 시 Level 1으로 복귀 |
| `📋 매일 아침 10시 뉴스 요약` | 중앙 상단, 현재 보고 있는 크론 작업명 표시 |

##### 각 행 구성

| 열 | 내용 | 너비 비중 |
|----|------|----------|
| **시간** | `MM-DD HH:MM` 형식. 세션 `created_at` | 15% |
| **세션 ID** | UUID 앞 8자리 + `...` | 20% |
| **마지막 AI 응답** | 해당 세션의 마지막 assistant 메시지 content 앞 **20자 + `...`** | 65% |

- **행 클릭 시**: Level 3 (세션 상세 로그)로 전환
- **페이지네이션**: 하단에 `[◀] [1 / 3] [▶]`. 한 페이지당 20행. DB 페이징 쿼리
  - **엣지 케이스**: 1페이지만 있어도 `[◀] [1/1] [▶]` 그대로 표시 (화살표 비활성화). 0페이지(데이터 없음)도 `[◀] [1/1] [▶]` 표시 + 중앙에 빈 상태 메시지 ("실행 기록이 없습니다")
  - **화살표 비활성화 조건**: 첫 페이지면 ◀ 비활성, 마지막 페이지면 ▶ 비활성, 1페이지만 있으면 둘 다 비활성
- **데이터 정렬**: `created_at DESC` (최신순)

│  │                 │ │  │     │ AI 최종 답변 (펼침)  │ │ │
│  │                 │ │  │     └──────────────────────┘ │ │
│  │                 │ │  │                               │ │
│  │                 │ │  │  (메인 UI 로그와 동일한       │ │ │
│  │                 │ │  │   포맷으로 표시)              │ │ │
│  │  (스크롤)       │ │  │                               │ │ │
│  │                 │ │  └───────────────────────────────┘ │ │
│  └─────────────────┘ │                                   │  │
│                       │              [✕ 닫기]             │  │
└───────────────────────┴───────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

##### 좌측 패널 — 시간 목록 (축소형)

| 상태 | 표시 |
|------|------|
| **기본** | 각 세션의 `created_at`을 `MM-DD HH:MM` 형식으로만 표시 |
| **선택됨** | `07-21 10:00 ◀` — 현재 보고 있는 세션. 우측 화살표 + 하이라이트 |
| **클릭 시** | 해당 세션의 로그를 우측 패널에 로드. 선택 표시 이동 |

- **너비**: 약 15% (120px). 세션 ID, 마지막 응답 등은 표시하지 않음
- **스크롤**: 독립적 스크롤 (좌우 패널 각각 QScrollArea)
- **변환 애니메이션** (선택): Level 2에서 Level 3로 전환 시, 좌측 패널이 **확장 → 축소**되는 부드러운 전환
  - Level 2: 전체 폭 (100%) — 시간 + 세션ID + 마지막응답
  - Level 3: 좌측 15% — 시간만 표시

##### 우측 패널 — 세션 로그

- 메인 윈도우의 **세션 로그 영역과 동일한 포맷**으로 표시
- 사용자 메시지 (크론 프롬프트) → AI 응답 블록 (툴 콜 접힘 + 최종 답변 펼침) 구조 동일
- **우측 상단 `✕ 닫기` 버튼**: 클릭 시 Level 2 (세션 목록)로 복귀. 좌측 패널이 다시 확장되어 전체 폭 표시
- **데이터 소스**: `psjba_message` 테이블에서 `session_id`로 조회, `created_at ASC` 정렬

##### 전환 로직 요약

```
Level 1 (크론 목록)
  ├── 📋 로그 버튼 클릭 → Level 2 (세션 목록)
  │     ├── 세션 행 클릭 → Level 3 (세션 상세, 좌/우 분할)
  │     │     ├── 좌측 시간 클릭 → 다른 세션 로드 (우측만 갱신)
  │     │     └── ✕ 닫기 → Level 2로 복귀 (좌측 확장)
  │     └── ◀ 크론 목록으로 → Level 1로 복귀
  └── (➕ 추가 / ✏️ 수정 / 🗑️ 삭제 / ▶ 실행) → 각각 다이얼로그
```

### 로그 탭 상세 — 2단계 드릴다운 구조

로그 탭은 **2단계 드릴다운(drill-down)** 으로 동작하며, CRON 탭과 유사하지만 Level 2까지만 있다.

```
┌──────────────────────────────────────────────────────────┐
│  [ 설정 ]  [ CRON ]  [ 로그 ▼ ]                          │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  ┌─ 로그 콘텐츠 영역 (QStackedWidget으로 2개 뷰 전환) ──┐│
│  │                                                      ││
│  │  ● Level 1: 모든 세션 목록                          ││
│  │  ● Level 2: 특정 세션의 상세 로그                   ││
│  │                                                      ││
│  └──────────────────────────────────────────────────────┘│
└──────────────────────────────────────────────────────────┘
```

- **추가 버튼 없음** — 로그 탭은 조회 전용이므로 `➕ 추가` 버튼 없음
- CRON과 달리 실행 기록 하위 단계(CRON Level 2→3) 없이, 세션 목록(Level 1) → 세션 상세(Level 2)로 바로 이동

---

#### Level 1 — 모든 세션 목록 (기본 화면)

DB에 저장된 **모든 세션(chat + cron)** 을 목록으로 표시한다. CRON의 Level 2와 유사하지만, **타입 컬럼이 추가**되고 모든 세션을 대상으로 한다.

```
┌──────────────────────────────────────────────────────────┐
│  [ 설정 ]  [ CRON ]  [ 로그 ]                            │
├──────────────────────────────────────────────────────────┤
│  ┌─ 세션 목록 테이블 ─────────────────────────────────┐  │
│  │                                                     │  │
│  │  ┌──────────────────────────────────────────────┐  │  │
│  │  │ 💬 채팅  │ 07-21 14:23 │ abc123... │ "오늘 날씨..."  │  │  │
│  │  ├──────────────────────────────────────────────┤  │  │
│  │  │ ⏰ 크론  │ 07-21 10:00 │ def456... │ "매일 아침..."  │  │  │
│  │  ├──────────────────────────────────────────────┤  │  │
│  │  │ 💬 채팅  │ 07-20 22:15 │ ghi789... │ "주식 분석..."  │  │  │
│  │  ├──────────────────────────────────────────────┤  │  │
│  │  │ ⏰ 크론  │ 07-20 10:00 │ jkl012... │ "뉴스 요약:..."  │  │  │
│  │  ├──────────────────────────────────────────────┤  │  │
│  │  │ 💬 채팅  │ 07-19 18:30 │ mno345... │ "메일 보내... "  │  │  │
│  │  └──────────────────────────────────────────────┘  │  │
│  │                                                     │  │
│  │                                     [◀] [1 / 1] [▶] │  │
│  │                                     (페이지네이션)   │  │
│  └─────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────┘
```

##### 각 행 컬럼

| 컬럼 | 내용 | 너비 비중 | 정렬 |
|------|------|----------|------|
| **타입** | 세션 type 표시. `💬 채팅` (type=chat) / `⏰ 크론` (type=cron) | 10% | 중앙 |
| **시간** | `MM-DD HH:MM` 형식. 세션 `created_at` | 15% | 좌측 |
| **세션 ID** | UUID 앞 8자리 + `...` | 20% | 좌측 |
| **처음 요청 프롬프트** | 해당 세션의 첫 번째 user 메시지 content 앞 **n자리** + `...` | 55% | 좌측 |

- **n자리 처리**: 첫 번째 user 메시지 전송 후 **자동으로** 제목을 갱신. 첫 번째 user 메시지의 앞 50자를 기본값으로 표시, 50자 초과 시 `...` 생략
- 첫 번째 user 메시지가 없는 경우 (빈 세션) → `"(내용 없음)"` 표시
- **정렬**: `created_at DESC` (최신순)
- **페이지네이션**: 하단 `[◀] [1 / N] [▶]`, 한 페이지당 20행, DB 페이징 쿼리
  - **엣지 케이스**: 1페이지만 있어도 `[◀] [1/1] [▶]` 그대로 표시 (화살표 비활성화). 0페이지(데이터 없음)도 `[◀] [1/1] [▶]` 표시 + 중앙에 빈 상태 메시지 ("세션이 없습니다")
  - **화살표 비활성화 조건**: 첫 페이지면 ◀ 비활성, 마지막 페이지면 ▶ 비활성, 1페이지만 있으면 둘 다 비활성
- **행 클릭 시**: Level 2 (세션 상세 로그)로 전환

##### 데이터 소스

- `psjba_session` 테이블에서 **모든 type** (chat + cron) 조회
- JOIN: 첫 번째 user 메시지 (psjba_message에서 session_id 기준, role='user', created_at ASC LIMIT 1)
- 조건: status = 'active' 또는 'archived' (deleted 제외)

---

#### Level 2 — 세션 상세 로그 (특정 세션 클릭 시)

Level 1에서 세션 행을 클릭하면, **좌/우 분할 레이아웃**으로 전환되어 해당 세션의 전체 로그를 표시한다. CRON Level 3과 동일한 구조.

```
┌──────────────────────────────────────────────────────────┐
│  [ 설정 ]  [ CRON ]  [ 로그 ]                            │
├──────────────────────────────────────────────────────────┤
│  ◀ 세션 목록으로                                         │
├──────────────────────┬───────────────────────────────────┤
│  ┌─ 시간 목록 ─────┐ │  ┌─ 세션 로그 영역 ────────────┐ │
│  │                 │ │  │                               │ │
│  │  07-21 14:23 ◀  │ │  │  👤 사용자 메시지            │ │
│  │  07-20 22:15    │ │  │  "오늘 날씨 알려줘"          │ │
│  │  07-19 18:30    │ │  │                               │ │
│  │                 │ │  │  🤖 ┌──────────────────────┐ │ │
│  │                 │ │  │     │ ▶ browser_navigate   │ │ │
│  │                 │ │  │     │ ▶ browser_snapshot   │ │ │
│  │                 │ │  │     ├──────────────────────┤ │ │
│  │                 │ │  │     │ 오늘 날씨는 맑습...  │ │ │
│  │                 │ │  │     └──────────────────────┘ │ │
│  │                 │ │  │                               │ │
│  │  (스크롤)       │ │  │  (메인 UI 로그와 동일한      │ │ │
│  │                 │ │  │   포맷으로 표시)              │ │ │
│  │                 │ │  └───────────────────────────────┘ │ │
│  └─────────────────┘ │                                   │  │
│                       │              [✕ 닫기]             │  │
└───────────────────────┴───────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

##### 헤더 영역

| 요소 | 설명 |
|------|------|
| `◀ 세션 목록으로` | 좌측 상단 뒤로가기 버튼. 클릭 시 Level 1으로 복귀 |
| (세션 정보 표시 없음) | 헤더에는 뒤로가기 버튼만 표시. 세션 상세 정보는 로그 영역에서 확인 |

##### 좌측 패널 — 시간 목록 (축소형)

Level 1에서 표시되던 **전체 세션 목록**을 시간만 축약하여 표시한다.

| 상태 | 표시 |
|------|------|
| **기본** | 각 세션의 `created_at`을 `MM-DD HH:MM` 형식으로만 표시 |
| **선택됨** | `07-21 14:23 ◀` — 현재 보고 있는 세션. 우측 화살표 + 하이라이트 |
| **클릭 시** | 해당 세션의 로그를 우측 패널에 로드. 선택 표시 이동 |

- **너비**: 약 15% (120px)
- **스크롤**: 독립적 스크롤 (좌우 패널 각각 QScrollArea)
- **전환 애니메이션**: Level 1 → Level 2 전환 시 좌측 패널이 **축소** (전체 테이블 → 시간만 목록)
- **데이터**: 현재 페이지의 세션만 시간 목록으로 표시 (페이지네이션 범위 내)

##### 우측 패널 — 세션 로그

- 메인 윈도우의 **세션 로그 영역과 동일한 포맷**으로 표시
- 사용자 메시지 → AI 응답 블록 (툴 콜 접힘 + 최종 답변 펼침) 구조 동일
- **우측 상단 `✕ 닫기` 버튼**: 클릭 시 Level 1 (세션 목록)로 복귀. 좌측 패널이 다시 확장되어 전체 폭 테이블 표시
- **데이터 소스**: `psjba_message` 테이블에서 `session_id`로 조회, `created_at ASC` 정렬

##### 전환 로직 요약

```
Level 1 (세션 목록 — 전체 테이블)
  └── 세션 행 클릭 → Level 2 (세션 상세, 좌/우 분할)
        ├── 좌측 시간 클릭 → 다른 세션 로드 (우측 패널만 갱신)
        └── ✕ 닫기 → Level 1로 복귀 (좌측 확장 → 전체 테이블)
```

### 전송/중지 버튼 동작

| 상태 | 버튼 텍스트 | 동작 |
|------|-----------|------|
| 대기 (연결 됨) | 전송 | 프롬프트 전송 |
| 전송 직후 | (0.3초 비활성화 + 색상 변화) → 중지 | 착오 클릭 방지 |
| Agent 실행 중 | 중지 | LangGraph asyncio task 취소 |
| 중지 완료 | 전송 | 입력 활성화 |

### 입력 규칙
- Enter 키 = 전송
- Shift+Enter = 줄바꿈
- 전송 버튼 클릭 = 전송
- Agent 실행 중에는 전송 버튼이 "중지"로 변경
- 연결 상태가 "연결 됨"이고 Agent가 실행 중이 아닐 때만 입력 활성화

### asyncio 통합
PySide6의 이벤트 루프와 asyncio를 qasync 라이브러리로 통합. LangGraph 에이전트 실행은 별도 QObject에서 async 스트림으로 동작하며, 각 단계별 이벤트를 시그널로 UI에 전달. UI 블로킹 방지.
